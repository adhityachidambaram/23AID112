# Trees and Graphs – Real-Life Scenario Questions

## 🌳 Trees (5 Questions)

### 1. Family Hierarchy System
A genealogy app stores family members in a structure where each person has at most two parents.  
**Question:** How would you represent this using a tree? How would you find the lowest common ancestor of two people?

---

### 2. Company Organizational Structure
A company has a CEO, managers, and employees forming a hierarchy.  
**Question:** If an employee leaves, how would you efficiently reassign their subordinates using a tree structure?

---

### 3. File System Navigation
Your computer stores folders and files in a hierarchical structure.  
**Question:** How would you design a tree to represent this, and how would you implement a search for a file path like `/documents/projects/report.doc`?

---

### 4. Autocomplete Feature in Search Engines
When you type in a search bar, suggestions appear instantly.  
**Question:** How can a Trie (prefix tree) be used to store and retrieve suggestions efficiently?

---

### 5. Game Decision Making (AI)
In a chess game AI, each move leads to multiple possible future moves.  
**Question:** How can a decision tree help determine the best move using strategies like minimax?

---

## 🌐 Graphs (5 Questions)

### 6. Navigation Systems
Cities are connected by roads with distances.  
**Question:** How would you model this as a graph and find the shortest path between two locations?

---

### 7. Social Media Connections
Users are connected as friends or followers.  
**Question:** How would you suggest “People You May Know” using graph traversal?

---

### 8. Flight Route Optimization
Airports are nodes and flights are edges with costs.  
**Question:** How would you find the cheapest route from one city to another with possible layovers?

---

### 9. Network Connectivity
Devices are connected in a network.  
**Question:** How would you detect if the network has a failure point (critical node or edge)?

---

### 10. Delivery Route Planning
A delivery truck must visit multiple locations efficiently.  
**Question:** How would you model this using a graph and solve it using concepts like the Traveling Salesman Problem?
