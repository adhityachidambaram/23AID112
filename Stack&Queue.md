# Stack and Queue – Real-Life Scenario Questions

## Stack (LIFO – Last In, First Out)

1. You are using a text editor and keep pressing "Undo." Why is a stack the best data structure to implement this feature?

2. Plates are stacked one over another in a cafeteria. When someone takes a plate, they take the top one. Which stack operations are involved in this scenario?

3. While browsing the internet, you visit multiple pages and press the "Back" button. How does a stack help manage this browsing history?

4. During program execution, functions call other functions. How does the call stack manage these function calls?

5. You are asked to reverse a word using a data structure. Why is a stack suitable for this task?

6. People stand in a line to buy tickets at a counter. Which queue operations correspond to this scenario?

7. Multiple documents are sent to a printer from different users. Why is a queue used to manage print jobs?

8. Customers call a support center and are attended in order. What problem might occur if a queue is not used here?

9. Vehicles pass through a traffic signal in sequence. How does a queue model help in managing traffic flow?
